# ADR-0006: Region内部コード表の設定駆動化

## ステータス

Accepted（2026-08-20）

## コンテキスト

`docs/design/04_ドメイン設計.md` 4.4 の `Region` VOは「ISO 3166ベースの内部コード表」とあるが実値一覧が存在しない（`docs/design-review.md` #6, U7, A6 参照）。提供地域はビジネス判断で変動し、かつProviderのエンドポイント追加と連動する。

## 決定

`Region` を enum でハードコードせず、VO生成時に「設定された有効コード表に含まれるか」を検証する（未知コードは例外）。コード表は起動時ロードし、Admin APIで追加可能とする。初期値は実際にProviderエンドポイントを置く地域のみ（1〜2地域）とする。

## 影響（Consequences）

- **制約**: コード中に固定のRegion enumを持たない。ハードコードすると `docs/design/01_要件定義.md` NFR-EXT-001（Provider追加時にコア変更を不要とする）に違反する。
- **見直す条件**: 提供地域が正式に決定次第、設定ファイルへ追加するだけで対応完了する（コード変更不要）。
- **未決定**: 実際に対応するリージョンの範囲（提供国）はビジネス判断であり、本ADRでは決定しない。
- **関連**: `docs/design-review.md` #6 / U7 / A6。
