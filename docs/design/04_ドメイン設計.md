# 4. ドメイン設計

AI Provider Abstraction Platform（APAP）設計書 第4章

---

## 4.1 Bounded Context

| Context | 責務 | 主要Aggregate | 永続化方式 |
|---|---|---|---|
| Provider Context | Provider/Model/Alias/Capabilityの構成管理 | Provider, Model, ModelAlias, CapabilityDefinition | Event Sourcing |
| Routing Context | 候補解決・スコア・Policy | RoutingPolicy（+ Read Model: CandidateView, HealthView） | State + Read Model |
| Execution Context | 実行・Retry/Fallback/CB・Streaming | ExecutionRecord（短命）, CircuitBreakerState, BatchJob | State（BatchJobのみES） |
| Conversation Context | Session/Conversation/Memory | Session, Conversation, Memory | State |
| Prompt Context | Template/Validation規則 | PromptTemplate | State（バージョン管理） |
| Cost Context | 単価・Usage・Budget・Quota | PriceBook, Budget, QuotaPolicy | State + 集計Read Model |
| Audit Context | 監査記録・検索 | AuditRecord（追記専用） | Append-only |
| Plugin Context | Pluginライフサイクル | PluginRegistration | State |

## 4.2 Context Map

```
[Provider Context] --(Published Language: Candidate/Capability)--> [Routing Context]
[Provider Context] --(Customer/Supplier)--> [Plugin Context]      … AdapterのSPI提供
[Routing Context]  --(Published Language: FallbackChain)--> [Execution Context]
[Conversation Context] --(Open Host Service)--> [Execution Context] … Context組立
[Prompt Context]   --(OHS)--> [Execution Context]
[Cost Context]     --(Conformist: Usageイベント購読)--  [Execution Context]
[Audit Context]    --(Conformist: 全イベント購読)--     [全Context]
[CIAP(外部)]       --(ACL: TokenVerifier)--> [Execution/Provider Context]
[AACP(外部)]       --(OHS: 公開API)--        [Execution Context]
```

関係パターン: Provider→Routingは公開言語（安定スキーマ）で連携。Audit/CostはConformist（イベントをそのまま受容）。外部基盤とは腐敗防止層（ACL）を置く。

## 4.3 Entity / Aggregate

Aggregate Root を **太字** で示す。不変条件はAggregate内で強制。

### 4.3.1 Provider Aggregate（Provider Context）

| 要素 | 属性 | 不変条件 |
|---|---|---|
| **Provider**（Root） | providerId, name, adapterPluginId, spiVersion, endpoints[], authType, credentialRefs[], rateLimits, priority, regions[], status, tags[] | 状態遷移は2.6.1の遷移表のみ許可。ACTIVE化にはVALIDATING合格が必要。credentialRefは最低1つ |
| Endpoint（Entity） | endpointId, region, baseUrl, weight | regionはProvider.regions内 |
| CredentialRef（VO） | secretRef, version, state(ACTIVE/STANDBY/REVOKED) | ACTIVEは常に1つ |

### 4.3.2 Model Aggregate（Provider Context）

| 要素 | 属性 | 不変条件 |
|---|---|---|
| **Model**（Root） | modelId, providerId, modelName, version, capabilities[], contextWindow, maxOutputTokens, pricingRef, regions[], status, priority | 状態遷移は2.7のみ。RETIREDへの遷移はAlias参照ゼロが条件 |
| ModelCapability（Entity） | capabilityId, constraints（対応modality、最大入力、並列tool数等） | capabilityIdはCapability Registryに存在 |

### 4.3.3 ModelAlias Aggregate（Provider Context）

| 要素 | 属性 | 不変条件 |
|---|---|---|
| **ModelAlias**（Root） | aliasId, name, targets[]{modelId, weight} | weight合計=100。target ModelはACTIVEまたはTESTING。nameはテナントスコープで一意 |

### 4.3.4 Conversation Aggregate（Conversation Context）

| 要素 | 属性 | 不変条件 |
|---|---|---|
| **Conversation**（Root） | conversationId, sessionId, tenantId, title, status, turnCount | Turn seqは欠番なし単調増加。DELETED後の追記不可 |
| Turn（Entity） | turnId, seq, role, contentParts[], modelUsed?, usage?, createdAt | roleはsystem/user/assistant/toolのみ |

### 4.3.5 その他のAggregate

| Aggregate | Root属性（要約） | 不変条件（要約） |
|---|---|---|
| **Session** | sessionId, tenantId, principal, attributes, expiresAt, status | 失効後の利用不可 |
| **Memory** | memoryId, scope, content, embedding, importance, ttl | scopeを跨ぐ参照不可 |
| **RoutingPolicy** | policyId, scope, rules[], version, status | DENY削除は新バージョン発行のみ（履歴保持） |
| **CircuitBreakerState** | cbKey(provider,model), state, windowStats, openedAt, openCount | 遷移は2.13のみ |
| **BatchJob** | jobId, tenantId, targetCapability, items[], status, progress | 状態遷移は3.13のみ。COMPLETEDの結果は不変 |
| **PriceBook** | priceBookId, entries[]{modelId, inputPer1k, outputPer1k, currency, effectiveFrom} | 期間重複エントリ不可 |
| **Budget** | budgetId, tenantId, period, limit, thresholds[80,100], consumed | consumedは単調増加（期間リセットのみ） |
| **QuotaPolicy** | quotaId, tenantId, scope, period, limits{requests, tokens, cost} | — |
| **PromptTemplate** | templateId, name, version, body, variables[], status | 公開後のbody変更は新バージョン |
| **CapabilityDefinition** | capabilityId, name, inputSchema, outputSchema, streamable, status | 公開後のスキーマ変更は後方互換のみ |
| **PluginRegistration** | pluginId, version, spiVersion, signature, status(LOADED/UNLOADED/QUARANTINED) | 署名検証合格が必要 |

## 4.4 Value Object

| VO | 内容 | 制約 |
|---|---|---|
| ProviderId / ModelId / AliasId / TenantId / RequestId / ConversationId / SessionId | 型付きID | ULID形式、生成後不変 |
| CapabilityId | 能力識別子 | `[a-z_]{3,40}`、Registry登録済 |
| SemVer | SPI/Pluginバージョン | semver準拠、互換判定メソッド保持 |
| Money / Cost | amount(Decimal), currency | 負値不可、通貨混合演算不可 |
| Usage | inputTokens, outputTokens, totalTokens, estimated | total = in + out |
| TokenCount | 非負整数 | — |
| Region | リージョンコード | ISO 3166ベースの内部コード表 |
| FinishReason | 6値enum（2.9） | — |
| NormalizedError | code, category, message, retryable, fallbackable, providerDetail? | codeは13章のエラー体系 |
| RoutingConstraints / RoutingPreferences | 2.5.1の構造 | — |
| Score | 0.0–1.0 | 範囲外は生成時例外 |
| ContentPart | text \| image \| audio \| video \| json のUnion | modalityとCapability制約の整合 |
| CredentialRef | Secret Store参照キー + version | 値そのものは絶対に保持しない |
| Period | from, to | from < to |
| CbKey | (providerId, modelId) | — |

## 4.5 Repository（Domain Interface）

3.4に定義。補足規約: Repositoryは**Aggregate単位**（Turn単独のRepositoryは持たずConversationRepository経由）。Event Sourcing対象（Provider / Model / Alias / Policy / BatchJob）は `EventStoreRepository` + 各Repositoryが再構築を担当し、Read Modelはイベント購読側が構築。

## 4.6 Domain Service

| Domain Service | 責務 | 所属Context |
|---|---|---|
| RoutingDomainService | フィルタ→スコア→Chain構築の決定ロジック（2.5.2）。純粋関数として実装 | Routing |
| PolicyResolutionService | 4階層Policyのマージ・競合解決（3.14） | Routing |
| ContextAssemblyService | 履歴+Memory+入力のトークン予算内合成（2.16） | Conversation |
| TokenEstimationService | Model別Tokenizer抽象によるトークン推定 | Execution |
| CostCalculationService | Usage×PriceBook→Cost算出、期間按分 | Cost |
| CredentialRotationService | 新旧世代の検証付き切替手順（検証→STANDBY昇格→旧REVOKED） | Provider |
| ErrorClassificationService | AdapterException→NormalizedError分類（2.11の表） | Execution |
| CanaryResolutionService | Alias targets[] の重みに基づく決定的抽選（requestIdハッシュで再現性確保） | Provider |

## 4.7 Domain Event

命名: 過去形。共通属性: eventId(ULID), occurredAt, traceId, tenantId?, aggregateId, version。全一覧は14章。代表:

```
ProviderRegistered { providerId, name, adapterPluginId }
ProviderEnabled / ProviderDisabled / ProviderDraining { providerId, reason }
ProviderHealthChanged { providerId, from, to, evidence }
ModelRegistered { modelId, providerId, capabilities[] }
ModelStatusChanged { modelId, from, to }
AliasChanged { aliasId, oldTargets[], newTargets[] }
RequestReceived / RequestStarted { requestId, capabilityId, tenantId }
RequestCompleted { requestId, provider, model, usage, cost, durationMs }
RequestFailed { requestId, errorCode, attempts, fallbacks }
RetryExecuted { requestId, candidate, attempt, reason }
FallbackExecuted { requestId, fromCandidate, toCandidate, reason }
CircuitBreakerStateChanged { cbKey, from, to }
RateLimitExceeded { scope, tenantId?, providerId? }
TokenLimitExceeded { requestId, limit, actual }
QuotaExceeded { tenantId, quotaId, dimension }
CostThresholdExceeded { tenantId, budgetId, threshold, consumed }
CredentialRotated { providerId, oldVersion, newVersion }
ModelDiscovered { providerId, discoveredModels[] }
BatchJobSubmitted / BatchJobCompleted / BatchJobFailed { jobId, ... }
```

## 4.8 ER図（論理モデル）

PlantUML版は12章。主要リレーション:

```
PROVIDER 1--* MODEL 1--* MODEL_CAPABILITY *--1 CAPABILITY
MODEL *--* MODEL_ALIAS（ALIAS_TARGET中間、weight付き）
PROVIDER 1--* CREDENTIAL_REF
MODEL 1--* PRICE_ENTRY
TENANT 1--* SESSION 1--* CONVERSATION 1--* TURN
TENANT 1--* MEMORY / QUOTA_POLICY / BUDGET / ROUTING_POLICY
REQUEST(AuditRecord) *--1 PROVIDER, *--1 MODEL, *--0..1 CONVERSATION
BATCH_JOB 1--* BATCH_ITEM
PLUGIN 1--* PROVIDER（adapter_plugin_id）
EVENT_STORE（streamId = AggregateId）: 全ES対象Aggregateのイベント列
```
