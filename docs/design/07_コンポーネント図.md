# 7. コンポーネント図

AI Provider Abstraction Platform（APAP）設計書 第7章（PlantUML）

---

```plantuml
@startuml component_apap
skinparam componentStyle rectangle

package "利用システム" {
  [AI Agent (AACP)] as AACP
  [Workflow Engine] as WF
  [Apps (Web/Mobile/Desktop/IoT/CLI/Batch)] as APPS
  [管理システム] as ADMIN
}

node "APAP" {
  package "Presentation" {
    [AI Gateway] as GW
    [Admin API] as ADMAPI
  }

  package "Application Core" {
    [Execution Engine] as EX
    [Streaming Engine] as SE
    [Prompt Engine] as PE
    [Routing Engine] as RT
    [Capability Resolver] as CR
    [Fallback Engine] as FB
    [Retry Engine] as RE
    [Circuit Breaker] as CB
    [Rate Limiter] as RL
    [Quota Manager] as QM
    [Cache Engine] as CA
    [Context Manager] as CM
    [Conversation Manager] as CV
    [Session Manager] as SM
    [Request Mapper] as RQM
    [Response Mapper] as RSM
  }

  package "Platform Services" {
    [Provider Manager] as PM
    [Model Manager] as MM
    [Plugin Manager] as PLM
    [Cost Engine] as CE
    [Audit Engine] as AE
    [Monitoring Engine] as MO
    [Scheduler] as SC
  }

  package "Provider Adapter Layer (Plugins)" {
    [Adapter A] as ADA
    [Adapter B] as ADB
    [Adapter N ...] as ADN
  }

  package "Infrastructure" {
    [Event Bus] as EV
    [Secret Store Client] as SS
    [Config/Policy Store] as PS
    [Cache Store] as CS
    [Event Store / DB] as DB
    [Read Model Store] as RM
    [Audit Store (WORM)] as AS
    [Vector Store] as VS
  }
}

cloud "外部AI Provider群" {
  [Provider A API] as PVA
  [Provider B API] as PVB
}
[CIAP (認証基盤)] as CIAP
[監視基盤 (Metrics/Trace/Log)] as OBS

' 利用側
AACP --> GW : REST/gRPC/SSE

' Gateway

' 実行系

FB --> RE

FB --> RSM

SE --> RSM

' ルーティング
RT --> CR

RT --> PS : Policy

' Adapter
RQM --> ADA
RQM --> ADB
RQM --> ADN

ADB --> PVB

' 管理系

' イベント・観測

@enduml
```

**補足**:

| 接続 | プロトコル/契約 |
|---|---|
| 利用システム → AI Gateway | REST(OpenAPI) / gRPC(Protobuf) / SSE。SDKは定義から生成 |
| Gateway → CIAP | OIDC/JWT検証（JWKSキャッシュ、ACL経由） |
| Core → Adapter | `ProviderAdapter` SPI（プロセス内Plugin。隔離要件が高い場合はサイドカープロセス + gRPC化可能。SPI契約は同一） |
| Adapter → Provider | Provider固有（Adapter内に閉じる） |
| Core → Event Bus | at-least-once、Aggregate単位順序保証 |
| Audit Store | 追記専用（WORM） |
