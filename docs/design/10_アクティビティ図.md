## 10.1 リクエスト実行全体フロー

```plantuml
@startuml activity_request
start
:リクエスト受信;
:CIAPトークン検証・テナント解決;
if (認証OK?) then (yes)
else (no)
  :401/403返却;
  stop
endif
:入口Rate Limit(テナント);
if (許容内?) then (yes)
else (no)
  :429返却 + RateLimitExceeded発火;
  stop
endif
:Conversation履歴ロード(指定時);
:Prompt Pipeline
(Validation→Optimization→Rendering);
if (Validation合格?) then (yes)
else (no)
  :400返却(PROMPT_VALIDATION_FAILED);
  stop
endif
:Cache照会;
if (hit?) then (yes)
  :cached=trueで応答返却;
  stop
else (no)
endif
:候補解決(Capability Resolver);
if (候補あり?) then (yes)
else (no)
  :404 CAPABILITY_NOT_AVAILABLE;
  stop
endif
:Routing(フィルタ→スコア→Chain);
:Quota事前チェック・予約;
if (Quota内?) then (yes)
else (no)
  :429 QUOTA_EXCEEDED発火;
  stop
endif
:Fallback Chain実行(10.2);
if (成功?) then (yes)
  :Response正規化;
  :Cost算出・Usage記録(非同期);
  :Turn永続化(指定時);
  :Cache保存(対象時);
  :200返却 + RequestCompleted;
  stop
else (no)
  :エラー正規化;
  :5xx/4xx返却 + RequestFailed;
  stop
endif
@enduml
```

## 10.2 Fallback Chain実行（Retry内包）

```plantuml
@startuml activity_fallback
start
:chain = [c1..cN], i = 1;
repeat
  :candidate = chain[i];
  if (CB state == OPEN?) then (yes)
    :スキップ;
  else (no)
    :Prompt再圧縮(refit, 候補のcontext制約);
    :attempt = 1;
    repeat
      :CB tryAcquire / RateLimiter acquire;
      :Adapter execute(タイムアウト予算内);
      if (成功?) then (yes)
        :recordSuccess;
        :Success返却;
        stop
      else (no)
        :エラー分類(NormalizedError);
        :recordFailure;
        if (リトライ可 かつ attempt < max かつ 予算残あり?) then (yes)
          :backoff待機(指数+jitter / Retry-After);
          :RetryExecuted発火;
          :attempt++;
        else (no)
          break
        endif
      endif
    repeat while (true)
    if (fallback可 かつ 予算残 > 次候補p50?) then (yes)
      :FallbackExecuted発火;
    else (no)
      :Failure返却(最終エラー);
      stop
    endif
  endif
  :i++;
repeat while (i <= N)
:Failure返却(全候補失敗) + RequestFailed;
stop
@enduml
```

## 10.3 Routing決定フロー

```plantuml
@startuml activity_routing
start
:候補集合 = Capability Resolver.resolve(capability, alias?);
if (alias指定?) then (yes)
  :Canary抽選(hash(requestId)%100)で
targets[]からModel確定;
endif
partition "ハードフィルタ" {
  :Provider/Model Status確認;
  :Circuit Breaker OPEN除外;
  :Provider Health DOWN除外;
  :Region制約適用;
  :Policy DENY適用(4階層);
  :テナント権限フィルタ;
  :Quota残量確認;
}
if (候補残あり?) then (yes)
else (no)
  :NO_CANDIDATE_AVAILABLEエラー;
  stop
endif
partition "スコアリング" {
  :S_cost / S_latency / S_avail / S_priority算出;
  :optimize_forとPolicyから重み決定;
  :合成スコア計算;
}
:Sticky補正(+0.05, conversation一致時);
:上位群(差0.02以内)から重み付きRR選択;
:スコア降順で最大fallback_depth件をChain化;
:RoutingDecision記録(Audit);
stop
@enduml
```

## 10.5 Streaming処理フロー

```plantuml
@startuml activity_streaming
start
:SSE/gRPC stream確立;
:Prompt/Routing/Quota(10.1と同一);
:adapter.executeStream()開始;
if (初回チャンク受信?) then (yes)
  :message_start送出;
else (失敗)
  :Fallback判定(10.2)
→次候補でストリーム再開;
endif
while (Provider終端でない)
  :AdapterChunk取得(pull);
  :正規化(content_delta/tool_call_delta);
  if (クライアントバッファ超過?) then (yes)
    :Provider読取を一時停止;
  endif
  :チャンク送出;
  if (アイドル60s or 全体300s超過?) then (yes)
    :errorチャンク送出→ABORTED;
    stop
  endif
  if (クライアント切断?) then (yes)
    :Providerへcancel伝播;
    :部分usageで確定・監査;
    stop
  endif
endwhile
:usage確定→usageチャンク+message_end送出;
:Cost算出/Turn永続化/RequestCompleted;
stop
@enduml
```
