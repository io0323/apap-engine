# 11. デプロイメント図

AI Provider Abstraction Platform（APAP）設計書 第11章（PlantUML）

---

```plantuml
@startuml deployment_apap
skinparam nodeStyle rectangle

node "Kubernetes Cluster (Region 1)" {
  node "Ingress / L7 LB" as LB {
    artifact "TLS終端 / WAF"
  }
  node "apap-gateway Pods (HPA: 3..N)" as GWP {
    artifact "AI Gateway"
    artifact "Admin API"
  }
  node "apap-core Pods (HPA: 3..N)" as COREP {
    artifact "Execution/Routing/Prompt/Context Engine"
    artifact "Adapter Plugins (プロセス内 or サイドカー)"
  }
  node "apap-worker Pods (2..N)" as WKP {
    artifact "Scheduler(リーダー選出)"
    artifact "Batch Executor"
    artifact "Read Model Projector"
    artifact "Audit Consumer"
  }
}

node "データ層 (マネージド/クラスタ)" {
  database "RDB\n(構成/Conversation/Usage)" as RDB
  database "Event Store\n(追記専用ストリーム)" as ES
  database "分散KVS\n(Cache/RateLimit/CB状態)" as KVS
  database "Vector Store\n(Memory)" as VS
  database "WORM Storage\n(Audit, 400日)" as WORM
  queue "Event Bus\n(at-least-once)" as BUS
  node "Secret Store\n(KMS連携)" as SEC
}

node "観測基盤" as OBS {
  artifact "Metrics(OpenMetrics)"
  artifact "Tracing(W3C)"
  artifact "Log(JSON)"
}

cloud "外部AI Provider群\n(複数リージョン)" as PV
node "CIAP" as CIAP
node "利用システム" as APPS

APPS --> LB : HTTPS/TLS1.3\n(REST/gRPC/SSE)
LB --> GWP
GWP --> CIAP : JWT検証(JWKS)
GWP --> COREP : gRPC(mTLS)
COREP --> PV : HTTPS(Adapter経由)
COREP --> KVS
COREP --> RDB
COREP --> VS
COREP --> SEC : Credential都度取得
COREP --> BUS : イベント発行
WKP --> BUS : 購読
WKP --> ES
WKP --> WORM
WKP --> RDB : Read Model
GWP --> OBS
COREP --> OBS
WKP --> OBS

node "Kubernetes Cluster (Region 2, Active-Active)" as R2
APPS --> R2 : GeoDNS/GSLB
R2 --> PV
note bottom of R2 : Region 1と同一構成。\n構成データは非同期レプリケーション。\nCache/CB状態はリージョンローカル。
@enduml
```

**配置方針**:

| 項目 | 方針 |
|---|---|
| ステートレス性 | gateway / core Podは状態を持たない（NFR-AVL-003）。状態は全てデータ層へ |
| スケール | HPA。gateway: CPU+接続数、core: CPU+キュー長、worker: ラグ |
| Plugin配置 | 既定はcore Podプロセス内ロード。隔離要求が高いAdapterはサイドカーコンテナ（同一SPI、gRPCブリッジ） |
| Scheduler | workerでリーダー選出（単一実行保証） |
| マルチリージョン | Active-Active。構成系（Provider/Model/Policy）はRegion 1をソースに非同期複製。実行系状態（Cache/CB/RateLimit）はリージョンローカル |
| ゼロダウンタイム | ローリングアップデート + DRAINING（PreStopでin-flight完遂、Streaming最大300s猶予） |
| ネットワーク | 外部TLS1.3、内部mTLS、Adapter→Providerはegress制御（Provider毎に許可先を限定 = Provider Isolation） |
