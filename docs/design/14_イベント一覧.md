# 14. イベント一覧

AI Provider Abstraction Platform（APAP）設計書 第14章

共通属性: `eventId`(ULID) / `occurredAt` / `traceId` / `tenantId?` / `aggregateId` / `version`。配送: Event Bus経由 at-least-once（購読側はeventIdで冪等処理）。順序: Aggregate単位で保証。

---

## 14.1 Provider / Model / Plugin系

| イベント名 | 発火元 | 購読先 | 用途 |
|---|---|---|---|
| ProviderRegistered | Provider Manager | Audit, Read Model Projector | 登録記録、Discovery View更新 |
| ProviderValidated | Provider Manager | Audit, 管理通知 | 検証合格記録 |
| ProviderEnabled | Provider Manager | Routing Engine, Audit, Read Model | 候補集合へ追加 |
| ProviderDraining | Provider Manager | Routing Engine, Audit | 新規ルーティング停止 |
| ProviderDisabled | Provider Manager | Routing Engine, Cache Engine, Audit | 候補除外、関連Cache無効化 |
| ProviderDeleted | Provider Manager | Audit, Read Model | 論理削除記録 |
| ProviderHealthChanged | Health Store（Scheduler probe + パッシブ判定） | Routing Engine, Monitoring/Alerting, Audit | 候補への即時反映、アラート |
| ModelRegistered | Model Manager | Routing Engine, Read Model, Audit | 候補集合更新、Capability View更新 |
| ModelStatusChanged | Model Manager | Routing Engine, Cache Engine, Audit | DEPRECATED/RETIRED時の候補除外 |
| ModelDiscovered | Scheduler（discoverModels実行） | 管理通知, Read Model | 新Model候補の運用者承認フロー起動 |
| AliasChanged | Model Manager | Routing Engine, Cache Engine（Alias配下無効化）, Audit | Canary/切替の即時反映 |
| PluginLoaded / PluginUnloaded | Plugin Manager | Provider Manager, Audit | Adapter利用可否の更新 |
| PluginQuarantined | Plugin Manager | Alerting, Audit | 署名/SPI不適合の隔離通知 |

## 14.2 リクエスト実行系

| イベント名 | 発火元 | 購読先 | 用途 |
|---|---|---|---|
| RequestReceived | AI Gateway | Monitoring | 受信数計測 |
| RequestStarted | Execution Engine | Monitoring | 実行開始計測（Cache hit時は発火しない） |
| RequestCompleted | Execution Engine / Streaming Engine | Audit Engine, Cost Engine, Usage Read Model, Monitoring | 監査記録、コスト計上、集計、SLO |
| RequestFailed | Fallback Engine / Execution Engine | Audit Engine, Monitoring/Alerting, Usage Read Model | 失敗監査、エラー率算出 |
| RequestCancelled | Streaming Engine / Gateway | Audit, Cost Engine | 切断時の部分Usage確定 |
| RetryExecuted | Attempt Executor | Monitoring, Audit | リトライ率計測、原因分析 |
| FallbackExecuted | Fallback Engine | Monitoring/Alerting, Audit | Fallback率計測、Provider品質分析 |
| CircuitBreakerStateChanged | Circuit Breaker | Monitoring/Alerting, Audit | 遮断の可視化・通知 |
| CacheHit / CacheStored | Cache Engine | Monitoring | Hit率計測（Audit対象外・高頻度のためメトリクスのみ） |
| StreamOpened / StreamClosed / StreamAborted | Streaming Engine | Monitoring | 同時接続・異常終了の計測 |

## 14.3 制限・コスト系

| イベント名 | 発火元 | 購読先 | 用途 |
|---|---|---|---|
| RateLimitExceeded | Rate Limiter | Monitoring/Alerting, Audit | 流量超過の検知・テナント通知 |
| TokenLimitExceeded | Context Manager / Prompt Engine | Monitoring, Audit | context超過の分析（FR-CTX-003） |
| QuotaExceeded | Quota Manager | Alerting, Audit, 管理通知 | 期間上限到達の通知・遮断記録 |
| CostThresholdExceeded | Cost Engine（Budget監視） | Alerting, Routing Engine（Policy発動）, 管理通知 | 80%/100%閾値アラート、低コストModelへの自動切替トリガ |
| BudgetPeriodReset | Scheduler | Cost Engine, Read Model | 期間繰越処理 |

## 14.4 セキュリティ・構成系

| イベント名 | 発火元 | 購読先 | 用途 |
|---|---|---|---|
| CredentialRotated | Rotate Credential Service | Audit, Alerting（失敗時）, Provider Manager | ローテーション監査 |
| CredentialValidationFailed | Provider Adapter / Rotation Service | Alerting, Provider Manager（SUSPEND判断） | 認証異常の即時検知 |
| PolicyUpdated | Manage Policy Service | Routing Engine, Audit, Read Model | Policy即時反映 |
| QuotaPolicyUpdated / BudgetUpdated | Admin API | Quota Manager / Cost Engine, Audit | 上限変更反映 |
| AccessDenied | AI Gateway / Policy Evaluator | Audit, Monitoring | 権限拒否の監査（PERMISSION_DENIED時） |

## 14.5 Batch / Session系

| イベント名 | 発火元 | 購読先 | 用途 |
|---|---|---|---|
| BatchJobSubmitted | Batch Job Service | Scheduler, Audit | 実行キュー投入 |
| BatchJobStarted / BatchItemCompleted | Batch Executor | Read Model（進捗）, Monitoring | 進捗更新 |
| BatchJobCompleted / BatchJobFailed / BatchJobCancelled | Batch Executor | Webhook Notifier, Audit, Cost Engine | 完了通知（completion_webhook）、コスト確定 |
| SessionCreated / SessionExpired / SessionRevoked | Session Manager | Audit | セッション監査 |
| ConversationDeleted | Conversation Manager | Audit, Memory（関連削除） | データ削除の追跡（NFR-DAT-001） |
| MemoryStored / MemoryDeleted | Memory Repository経由（Capability実行） | Audit | 記憶操作の監査 |
